## Safety knobs

Several servers expose write controls. Keep them off unless you need writes:

| Variable | Effect |
| --- | --- |
| `POSTGRESQL_ALLOW_WRITES` | Enable write queries |
| `REDIS_ALLOW_WRITES` | Enable key mutation |
| `MONGODB_ALLOW_WRITE_PIPELINES` | Enable aggregation writes |
| `FILESYSTEM_ROOTS` | Sandbox the filesystem server |
| `FILESYSTEM_MAX_READ_BYTES` | Cap read size |
| `VERCEL_TEAM_ID` | Scope Vercel access to a team |

The root `.env.example` has the full set.

## Experimental and opt-in

`umt list` marks experimental servers explicitly; they may change or be removed.
Third-party MCP servers can be added as opt-in entries using the same
`mcpServers` shape. They are not part of the default bundle. One example is
Vynly (`@vynly/mcp`), a social network for AI-generated images and short video
with a free demo token on first call.

## Verify

```bash
umt list
umt search postgres
umt test github        # live MCP handshake
umt conformance        # registry config + local handshakes
```

If a server is missing, check whether it is disabled in this build and whether
its package is installed in workspace mode.
